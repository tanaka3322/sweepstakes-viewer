# 担当更新の中継（Apps Script）デプロイ手順

サイト（静的ページ）からは Google スプレッドシートへ直接書き込めないため、
この Apps Script を Webアプリとしてデプロイし、サイトの「担当を決めるボタン」が
ここへ POST して M列（担当）だけを更新する。

## 手順（むぎ想定・所要5分ほど）
1. 対象シート「懸賞_共通応募リスト」を開く → 拡張機能 → Apps Script
   （または script.google.com で新規プロジェクトを作り、`Code.gs` の内容を貼る）
2. `Code.gs` の内容をそのまま貼り付けて保存
3. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 実行ユーザー：自分
   - アクセスできるユーザー：全員
4. 発行された WebアプリURL（`https://script.google.com/macros/s/.../exec`）をコピー
5. サイト側 `public/config.js` の `endpoint` にそのURLを入れて commit / push
   （Vercel が自動で再デプロイする）
6. サイトで未振り分けの懸賞の「むぎ」ボタンを押し、シートの担当が変われば完了

## 注意
- コードを直したら「デプロイを管理」から新しいバージョンで再デプロイすること
  （URL は同じものを使い続ける）
- パスコードを変える場合は `Code.gs` の `PASSCODE` と `public/config.js` の
  `passcode` を同時に変える
- この中継が更新するのは M列（担当）だけ。他の列は変更しない作りになっている
